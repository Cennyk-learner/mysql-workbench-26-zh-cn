# MySQL Workbench 简体中文补丁

为 Apple 芯片 Mac 提供 MySQL Workbench 中文菜单和常用界面翻译。请先查看 Workbench 的版本，再选择对应的安装说明。

| Workbench 版本 | 补丁内容 | 安装说明 |
| --- | --- | --- |
| **8.0.47 CE ARM64** | 中文菜单、管理侧边栏、SQL 编辑器常用标签、执行输出区，以及侧边栏中文方框字修复 | [8.0 安装与恢复](workbench-8.0/README.md) |
| **26.10.0 ARM64** | 中文菜单、连接页面和常用前端界面 | [26.10 安装说明](README-26.md) |

8.0 补丁新增了系统苹方字体修复，用于解决自绘侧边栏在翻译后显示方框的问题。高级功能、部分弹窗和数据库错误信息仍有英文。两个版本的补丁分别校验各自的原版资源。

本仓库提供安装脚本与翻译词条。请从 Oracle 下载对应版本的 Workbench 安装包。[Oracle 下载页](https://dev.mysql.com/downloads/workbench/) · [版本归档](https://downloads.mysql.com/archives/workbench/)

欢迎通过 [Issues](https://github.com/Cennyk-learner/mysql-workbench-26-zh-cn/issues) 反馈漏译、误译和安装问题，并附上 Workbench 版本、芯片架构、macOS 版本及界面位置。
